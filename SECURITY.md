# Security

Please don't report security issues in public issues.

Use GitHub's private reporting instead: **Security › Report a vulnerability** on
[lakpriya1s/kinterm](https://github.com/lakpriya1s/kinterm/security/advisories/new).
Include what you found, how to reproduce it, and the KinTerm version.

You'll get a reply as soon as possible. Once it's fixed, the fix ships as a new release
through KinTerm's built-in updates.

If the issue is in the terminal core rather than KinTerm's agent features, it likely
affects Ghostty too. Please also see
[Ghostty's security policy](https://github.com/ghostty-org/ghostty/security).

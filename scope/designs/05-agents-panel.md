# 5 · Agents panel (⌘⇧A)

Source: [source/Agents.dc.html](source/Agents.dc.html)

A panel listing every agent across all windows.

- **Header:** "Filter agents…" search field, `⌘⇧A` hint.
- **Filter chips:** All N · Waiting N · Working N · Done N.
- **Columns:** face (small) · TAB (title + `Window 1 · tab 2 · branch`) ·
  DOING (waiting rows in amber) · ACCOUNT (color bar + name) · TIME.
- Sorted by urgency: waiting first.
- **Footer:** `↵ jump to tab` · `⌘J next waiting agent` · `N agents · N windows`.
- Enter or click jumps to that tab.
